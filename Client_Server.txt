Client and Server:
-------------------

Client:

	Client is request sender. it asks system to 1.get data 2. save date 3.update data 4. delete data
	
example:
Web browser
Mobile app
Another backend service
Java program calling an API

Client initiates communication

Server:

	Server is request handler.it receives the request , process the business logic, talks to database or other
services and sends back response.

Real-Life Example 🧠

ATM Machine

Client: ATM screen

Server: Bank system

ATM → "Give balance" → Bank Server
ATM ← "Your balance is ₹10,000" ← Bank Server

Client Responsibilities

Build request,Send correct data,Handle response/errors

Server Responsibilities

Validate request,Apply business logic,Return proper response

lient–Server in System Design

In system design, we focus on:

How many clients?

How many servers?

How servers scale?

How requests are balanced?

Many Clients → Load Balancer → Multiple Servers

One-Line Interview Answer (Basic)

A client sends requests to a server to perform an action, and the server processes the request and returns 
a response. In Java systems, the server is typically a Spring Boot application exposing APIs.
